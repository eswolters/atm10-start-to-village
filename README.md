# ATM10: Start to Village

A step-by-step checklist for **All the Mods 10** that takes a brand-new world to a fully automated medieval [MineColonies](https://minecolonies.com) town, with the tech (Create, Mekanism, Powah, AE2) hidden underneath it in an "undercroft".

## Use it

Open `index.html` in a browser. Tick steps off as you go; progress is kept in your browser's local storage. You can filter by layer (Surface / Undercroft) or by mod, and hide finished steps.

## The phases

1. Plan before you place a block
2. Survive and gear up
3. Found the colony
4. Dig the undercroft: first hidden tech
5. Build the AE2 brain
6. Grow the town to levels 2–3
7. Connect the colony to AE2 (includes a CC:Tweaked + Advanced Peripherals request-filler script)
8. Resource engines
9. Finish the town

## Notes

- ATM10 updates add and remove mods, so check JEI for recipes rather than relying on the guide.
- The Lua script has not been tested in-game. Advanced Peripherals has renamed some functions between versions; the script handles the known renames, but test it on a small scale first.
