# ATM10: Start to Village

A step-by-step checklist for **All the Mods 10** that takes a brand-new world to a fully automated medieval [MineColonies](https://minecolonies.com) town, with the tech (Create, Mekanism, Powah, AE2) hidden underneath it in an "undercroft".

## Use it

Open `index.html` in a browser. Each of the 67 steps explains why it matters and breaks into sub-steps you tick off (315 in total). Many steps also list key ingredients and sketch the machine layout. Progress is kept in your browser's local storage. You can filter by layer (Surface / Undercroft) or by mod, search, and hide finished steps.

## The phases

1. Plan before you place a block
2. Survive and gear up
3. Found the colony
4. Dig the undercroft: first hidden tech
5. Build the AE2 brain
6. Grow the town to levels 2–3
7. Connect the colony to AE2 (includes [`startup.lua`](startup.lua), a CC:Tweaked + Advanced Peripherals request-filler script)
8. Resource engines
9. Finish the town

## Notes

- ATM10 updates add and remove mods, so check JEI for recipes rather than relying on the guide.
- `startup.lua` was written against the Advanced Peripherals 1.21.1 source (`colony_integrator`, `me_bridge`, `isCraftable`) and falls back to the older names. It has not been tested in-game, so try it on a small scale first.
